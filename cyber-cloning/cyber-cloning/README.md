# Cyber Cloning
Enter a URL, download a ZIP (index.html + assets/) of that page.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. On vercel.com: Add New > Project > import the repo > Deploy (no settings needed).
Or with CLI: `npm i -g vercel` then `vercel --prod`.

Notes: Hobby plan allows big enough downloads for normal pages; JS-rendered apps may not clone fully.
